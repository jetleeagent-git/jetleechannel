2️⃣ Go-Live Workflow (Upload to Hostinger)

Step 1: Login to Hostinger → hpanel.hostinger.com
Step 2: Create a subdomain for each project
Domains → Subdomains → Create: e.g. dunernhouse.jetleechannel.sg
Set document root to e.g. /dunernhouse
Step 3: Upload the SEO-optimized index.html
File Manager → navigate to subdomain folder → Upload
Step 4: Upload images folder alongside index.html
Folder structure should be:
/dunernhouse/
  ├── index.html
  └── images/ (hero, gallery, etc.)
Step 5: Test the site
Visit https://dunernhouse.jetleechannel.sg — should load immediately
Step 6: Submit to Google Search Console
Add property → verify ownership (DNS TXT record or HTML file → submit sitemap)

3️⃣ Google Indexing Workflow

Step-by-Step to Get Indexed

  1. Site must be live — upload to Hostinger first, verify it loads
  2. Submit to Google Search Console
    • Go to search.google.com/search-console
    • Add property (URL prefix): e.g. https://dunernhouse.jetleechannel.sg
    • Verify ownership — easiest: DNS TXT record at domain registrar
  3. Request indexing
    • In Search Console → URL Inspection → paste your URL → "Request Indexing"
  4. Submit sitemap
    • Sitemap URL: https://[subdomain].jetleechannel.sg/sitemap.xml
    • This helps Google discover all pages faster
  5. Wait
    • Typically 1-7 days for initial indexing
    • Search "site:[subdomain].jetleechannel.sg" to verify
